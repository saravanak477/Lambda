# AWS Lambda with Python

## Project Overview
This project demonstrates AWS Lambda concepts using Python and Boto3.

## Technologies Used
- AWS Lambda
- Python
- Boto3
- Amazon S3

## Project Objective
To learn how to process files stored in Amazon S3 using AWS Lambda and Python.

## Key Learning
- AWS Lambda function basics
- Reading objects from Amazon S3
- Listing S3 bucket objects using Boto3
- Understanding serverless computing
